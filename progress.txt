2026-06-05 - workspace-yw1.7.1 - Dashboard sync repair action consumer

Fixed the dashboard-to-bot bridge for manual sync drift actions. Previously `/api/sync/action` inserted `repair` and best-effort `accept` rows into `sync_actions`, but the bot only listens to `bot_action_queue`, so manual repair could sit unprocessed and manual accept could remove drift without updating desired state from Discord. The route now queues `repair` and `accept` into `bot_action_queue`, and the bot action queue routes those actions to the existing sync repair functions.

2026-06-05 - workspace-yw1.7.2 - Deploy listener multi-guild scoping

Fixed the bot deploy listener so dashboard deploy requests are not limited to the primary configured guild. 2026-06-05 - workspace-dzm - Permission-overwrite drift accept honesty

Fixed sync drift accept behavior so channel/category permission-overwrite drift cannot report success unless the desired overwrites are actually updated. Because the current drift payload does not carry enough structured overwrite data to safely accept those changes, the dashboard API now rejects those accept requests with a manual-review error, and the bot also rejects any already-queued `sync_accept_drift` rows without retrying or calling `acceptDriftItem`. Direct repair-action accept now fails honestly too, so it cannot remove drift and write an accepted audit entry without changing overwrites.
