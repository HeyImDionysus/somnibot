Add Credentials

After runtime readiness, enter credentials for Discord and Supabase.

  1. Create a Discord application and bot, then copy the token, application ID, and client secret.
  2. In Supabase → Account → Access Tokens, create one Personal Access Token starting with sbp_.
  3. The launcher uses that token to discover the project and load its API keys. Leave database password blank for normal Supabase use.
⚠ No internet connection — credential validation and cloud sync require network access.

Database recovery

Back up the saved source database first. Logical dumps contain sensitive data and exclude storage object bytes and provider settings. Docker, PostgreSQL clients and the required cached dump image must already be available; nothing is installed automatically. Existing backups are preserved.
