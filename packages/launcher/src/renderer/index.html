Welcome to SomniBot

Let's get your bot online. You'll need two things:

1
Discord Bot Credentials

A bot token, application ID, and client secret from the Discord Developer Portal.

2
Supabase Project

A Supabase project URL, secret key, and publishable key for your database.

🤖

Create a Discord Bot

If you don't have a bot yet, create one in the Developer Portal:

  1. Go to discord.com/developers/applications
  2. Click New Application → name it → Create
  3. Go to Bot tab → Reset Token → copy the token
  4. Scroll down and enable all Privileged Gateway Intents
  5. Go to OAuth2 → copy the Client Secret
  6. Copy the Application ID from the General tab
🗄️

Set Up Supabase

Create a free Supabase project for your bot's database:

  1. Go to supabase.com/dashboard
  2. Create a new project (any region)
  3. Go to Settings → API
  4. Copy the Project URL
  5. Copy the anon/public key (publishable key)
  6. Copy the service_role key (secret key)
  7. Go to Settings → Database and note your database password
⚠ No internet connection — credential validation and cloud sync require network access.
