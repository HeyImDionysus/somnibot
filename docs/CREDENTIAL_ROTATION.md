# Credential Rotation Runbook

> V6 Audit Finding §1.2 — Document the rotation procedure for every secret.

## Quick Reference

| Secret | Where It Lives | Rotation Steps |
|--------|---------------|----------------|
| `DISCORD_TOKEN` | Discord Dev Portal → Bot → Reset Token | 1. Reset in portal 2. Update `.env` / launcher 3. Restart bot |
| `DISCORD_CLIENT_SECRET` | Discord Dev Portal → OAuth2 → Reset Secret | 1. Reset in portal 2. Update `.env` / launcher 3. Restart dashboard |
| `SUPABASE_SECRET_KEY` | Supabase Dashboard → Settings → API | 1. Rotate in Supabase dashboard 2. Update `.env` / launcher 3. Restart all services |
| `SUPABASE_PUBLISHABLE_KEY` / `SUPABASE_ANON_KEY` | Supabase Dashboard → Settings → API | 1. Copy new anon/publishable key 2. Update bot/server `.env` aliases 3. Restart services that read server env |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase Dashboard → Settings → API | 1. Copy the same anon/publishable key 2. Update dashboard `.env`, launcher, and hosting env vars 3. Rebuild/redeploy dashboard |
| `NEXTAUTH_SECRET` | Self-generated (`openssl rand -hex 32`) | 1. Generate new secret 2. Update `.env` 3. Restart dashboard (sessions invalidated) |
| `CSRF_SECRET` | Self-generated (`openssl rand -hex 32`) | 1. Generate new secret 2. Update `.env` 3. Restart dashboard |
| `DOWNLOAD_SIGNING_SECRET` | Self-generated (`openssl rand -hex 32`) | 1. Generate new secret 2. Update `.env` 3. Restart dashboard (existing signed URLs invalidated) |
| `PAYPAL_CLIENT_ID` | PayPal Developer Dashboard | 1. Create new REST app or rotate credentials 2. Update `.env` 3. Restart dashboard |
| `PAYPAL_CLIENT_SECRET` | PayPal Developer Dashboard | Same as PAYPAL_CLIENT_ID |
| `PAYPAL_WEBHOOK_ID` | PayPal Developer Dashboard → Webhooks | Only changes if you recreate the webhook endpoint |
| `LAVALINK_PASSWORD` | `services/lavalink/application.yml` + `.env` | 1. Update both files 2. Restart lavalink + bot |
| `SESSION_TOKEN` | Auto-generated by Electron launcher | Regenerated automatically on each launcher start — no manual rotation needed |

## Step-by-Step: Full Rotation (Compromise Response)

If you suspect any credential has been compromised, rotate **all** secrets:

### 1. Discord Credentials
```bash
# Reset bot token (immediately invalidates the old one)
# Discord Developer Portal → Bot → Reset Token
# Copy new token → update DISCORD_TOKEN

# Reset client secret
# Discord Developer Portal → OAuth2 → Reset Secret
# Copy new secret → update DISCORD_CLIENT_SECRET
```

### 2. Supabase Keys
```bash
# Supabase Dashboard → Settings → API → Rotate Keys
# Copy new service_role key → update SUPABASE_SECRET_KEY
# Copy new anon/publishable key → update server aliases:
#   SUPABASE_PUBLISHABLE_KEY or SUPABASE_ANON_KEY
# Copy the same key → update dashboard public env:
#   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
```

### 3. Application Secrets
```bash
# Generate new secrets
openssl rand -hex 32  # → NEXTAUTH_SECRET
openssl rand -hex 32  # → CSRF_SECRET
openssl rand -hex 32  # → DOWNLOAD_SIGNING_SECRET
```

### 4. PayPal (if applicable)
```bash
# PayPal Developer Dashboard → My Apps & Credentials
# Create new REST API app or rotate existing credentials
# Update PAYPAL_CLIENT_ID and PAYPAL_CLIENT_SECRET
```

### 5. Restart Everything
```bash
# Docker deployment
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d

# Launcher deployment
# Simply restart the launcher — it will use updated env/config
```

## Post-Rotation Checklist

- [ ] All services start without auth errors
- [ ] Bot appears online in Discord
- [ ] Dashboard was rebuilt/redeployed with the new `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- [ ] Dashboard login works (Discord OAuth)
- [ ] PayPal webhooks still arrive (check `/api/paypal/webhook` logs)
- [ ] Existing download links will fail (expected — they were signed with old secret)
- [ ] Users may need to re-login to dashboard (NEXTAUTH_SECRET change invalidates sessions)

## Preventive Schedule

| Frequency | Action |
|-----------|--------|
| Every 90 days | Rotate `NEXTAUTH_SECRET`, `CSRF_SECRET`, `DOWNLOAD_SIGNING_SECRET` |
| Every 180 days | Rotate PayPal credentials (if using PayPal) |
| On team member departure | Rotate ALL secrets |
| On suspected compromise | Rotate ALL secrets immediately |
